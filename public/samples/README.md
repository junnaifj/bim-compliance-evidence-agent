# Assessment IFC samples

These files are real open-source IFC models used as assessment fixtures. They are presented by model purpose rather than candidate identity. The deterministic engine applies exactly the same evidence policy to uploads and built-in samples.

The machine-readable source, licence, hash, schema and expected entity counts are in `manifest.json`.

- **Duplex residence** follows the xeokit SDK Apache-2.0 licence and is the small interactive demonstration model.
- **Medical–dental clinic** is attributed as “BSI (2020) Medical-Dental Test Files, buildingSMART International” under CC BY 4.0.
- **buildingSMART PCERT Architecture** is a CC BY 4.0 IFC4 negative control: no review target must be invented when the active rules have no applicable door.

The HKSAR Government regulation documents shown in the Rule-source library are deliberately not copied into this repository. The application links to the official publisher, and users may upload an authorised local copy for private preview and extraction.
